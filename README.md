# MeetingMind

> 工作会议**实时转录 + 结构化纪要**：谁说了什么（字幕流）、讨论了什么（议题分段）、定了什么（决议）、要做什么（待办），会后一键导出四格式。

纯前端 Web 应用，Chrome / Edge 桌面优先，数据默认留在本机。

---

## 1. 快速开始

```bash
cd meetingmind
npm install
npm run dev
```

打开 **http://localhost:5173/**（Vite 默认端口 5173，控制台会打印实际地址）。

### 跑之前必须知道的三件事

1. **用 Chrome 或 Edge（110+）**。Safari / Firefox 不支持浏览器原生实时识别，会自动降级为「仅录音」模式（见下节 L1）——产品仍可用，但不会边说边出字。
2. **必须在 `localhost` 或 HTTPS 下访问**。非安全上下文下浏览器禁用 `getUserMedia` 与 `SpeechRecognition`，这是浏览器硬限制，不是 bug；用局域网 IP（`http://192.168.x.x`）直连会拿不到麦克风。
3. **首次点「开始会议」会弹麦克风授权，必须点允许**。拒绝后会自动降级为「手动记录」模式（L2）。

## 2. 三种运行模式

模式由启动时自动探测决定，无需手动选择；降级时顶栏会有常驻提示。

| 模式 | 触发条件 | 表现 |
|---|---|---|
| **L0 实时识别** | 浏览器支持且识别服务可达 | 边说边出字，interim 灰字实时刷新，确认后入列 |
| **L1 仅录音** | 浏览器不支持 / 识别服务网络不通 / 8 秒探活无结果 | 不显示字幕，但**继续录音**，会后可用外部转录文本回填 |
| **L2 手动记录** | 无麦克风权限 / 无输入设备 / 非安全上下文 | 提供文本框边会边记 |

- L1 / L2 下，实时页都有**手动补录面板**：单行回车补录 1 条；整段粘贴外部转录按行批量导入（`Ctrl/Cmd + Enter` 提交）。
- 实时页底部有音量条与「能量突变提示」——**只提示，绝不自动改写发言人归属**。

### 关于说话人（重要，请如实预期）

**本产品不做声纹识别，不会自动认出"谁在说话"**。说话人归属靠三条路径，承诺的是"说得清是谁说的，且改起来很快"：

1. **会前**：预设参会人（≤12 人），自动分配不重复的颜色；
2. **会中**：点击头像条切换当前发言人，或 `Ctrl/Cmd + 1..9` 快速切换；
3. **会后**：单条改归属、**「从此处起批量改为 X」**（带影响条数预览）、**按发言人批量重归属**；删除参会人时其发言**不会丢失**，只转「未知发言人」。

## 3. 快捷键

| 快捷键 | 行为 | 生效条件 |
|---|---|---|
| `Ctrl/Cmd + 1..9` | 切到第 N 位当前发言人 | 会议进行中，非输入态 |
| `Ctrl/Cmd + K` | 跳到历史页并聚焦搜索框 | 全局 |
| `Ctrl/Cmd + Z` | 撤销（栈深 30 步） | 非输入态 |
| `Ctrl/Cmd + S` | 立即保存（阻止浏览器保存网页） | 全局 |
| `空格` | 暂停 / 继续录制 | 非输入态 |
| `Ctrl/Cmd + M` | ⭐ 打点（标记重点） | 会议进行中；可在设置里关闭该绑定 |
| `Esc` | 关闭弹窗 / 退出就地编辑 | 全局 |

> 会议累计时长**不含暂停**；发言时间码与录音时间轴严格对齐，可直接按时间码跳转播放。

## 4. 导出

| 格式 | 用途 |
|---|---|
| **Markdown（.md）** | 带 `# 标题` → 议题 → 决议 → 待办表格 → 完整发言附录，粘进飞书/语雀/Notion 效果最好 |
| **纯文本（.txt）** | 内容一致、无标记语法，适合贴进聊天窗口 |
| **JSON（.json）** | 完整快照（含 `schemaVersion`），可作备份与再导入 |
| **打印 HTML（.html）** | 内嵌 CSS + A4 分页，打开后 `Ctrl/Cmd + P` 直接出 PDF |

四格式**从同一份快照序列化，内容严格一致**。另有一键**复制待办清单**，支持三种风格：
`Markdown 表格` / `可读文本` / `TSV`（**可直接粘贴进 Excel**）。

文件名格式：`会议标题_YYYYMMDD.ext`（已剔除 Windows/Unix 非法字符）。

## 5. CloudBase 云端配置（可选，**不配也能完整使用**）

```bash
cp .env.example .env
```

```ini
VITE_CLOUDBASE_ENV=你的环境ID        # 云开发环境 → 环境 ID
VITE_CLOUDBASE_REGION=ap-shanghai
VITE_ENABLE_CLOUD=true              # 必须为 true 才会连接
```

**配了有什么用**
- 会议数据上云，多端同步与备份；
- 调用 AI 大模型（`hunyuan-2.0-instruct-20251111`，失败自动换 `hunyuan-exp`）做结构化整理：议题分段、决议抽取、待办抽取（负责人 / 截止日期 / 优先级）。

**不配的表现（这是设计如此，不是功能缺失）**
- 完全本地运行，数据存 IndexedDB；
- 结构化整理由**本地规则引擎**接管：按时间间隔与话题切换词分段，用中文决议/待办句式抽取，解析「明天/下周/11月3号」为具体日期，识别 `@姓名` 与「某某负责」为负责人；
- 全部功能（实时转录、整理、导出、历史检索）**照常可用**，只是整理结果是规则产出而非 AI 产出，需人工确认（候选条目呈虚线卡片，勾选后转实线）。

> 云端初始化有 **3 秒超时**，超时或失败自动降级为本地模式并提示，**不阻塞首屏**——首屏一律先按本地模式渲染完成。

## 6. 数据存在哪里

| 数据 | 位置 |
|---|---|
| 会议正文、发言、决议、待办 | IndexedDB，库名 **`meetingmind`**（v1） |
| 录音音频 | 同上 `audio` store，以 Blob 存放 |
| 语言/设备/开关等偏好 | localStorage |

- **刷新或崩溃后重开页面，会自动恢复未结束的会议**（顶栏出现恢复入口）。
- 会中每 5 秒防抖自动落盘；纪要页编辑 800ms 防抖保存；`Ctrl/Cmd + S` 可立即保存。
- 录音 Blob 较大，长期不用建议在历史页导出 JSON 备份后删除旧会议。

## 7. 已知限制（如实列出）

- **刷新页面恢复会议后会开始一段新录音，结束时会覆盖刷新前的那段音频**（未做分片追加）；**字幕不受影响**。
- 单场会议建议：参会人 **≤12 人**、发言 **≤2000 条**（约 3 小时）。
- **浏览器无法直接采集系统内部音频**（腾讯会议 / 飞书里对方的声音）。远程会议请用「扬声器外放 + 麦克风收音」，或安装虚拟声卡。
- **离开实时页时麦克风不会自动停止**（避免中途查看历史页丢失音频）。顶栏会常驻 **「会议进行中 · 麦克风收音中」** 提示，可从那里结束会议——**结束会议前记得先结束**。
- 待办的截止日期解析基于**会议开始时间**的本地时区；解析不出会留空，不做猜测。
- AI 整理结果中的溯源引用会与真实发言 ID 严格对齐，对不上的 ID 直接丢弃，**不会编造引用**。

## 8. 项目结构

```
src/
  core/
    speech/   语音降级：L0 实时识别 / L1 仅录音 / L2 手动记录，8 秒探活与自动重启
    audio/   录音与播放（MediaRecorder + AudioContext 音量 + 按时间码 seek 播放）
    repo/    双存储：LocalRepository（IndexedDB，唯一主实现）+ CloudRepository（云端镜像异步追写）
    struct/  结构化整理：RuleStructurer（本地规则，主路径）+ CloudAiStructurer（AI，超时回落规则）
    export/  四格式导出编排（md / txt / json / html）与待办清单文本
    cloud/   CloudBase 客户端：3s 超时探测、匿名登录、绝不阻塞首屏
  stores/    useMeetingStore（会话主状态：发言 / 参会人 / 议题 / 决议 / 待办 / 撤销栈）
             useUiStore（模式徽标、降级提示、偏好、Toast、确认弹窗）
  components/ AppHeader 顶栏 · common/ 通用 UI（导出菜单 / 确认框 / 头像）
              live/ 实时页组件 · review/ 纪要页组件
  pages/     HistoryPage 历史 · LivePage 实时 · ReviewPage 纪要
```

> 性能要点：interim 文本**不进**发言列表，独立气泡渲染；发言列表用 `@tanstack/react-virtual` 窗口化 + 行级细粒度订阅，600+ 条不掉帧；IndexedDB 按 `seq` 水位增量写。

## 9. 常用命令

```bash
npm run dev         # 开发服务器（默认 http://localhost:5173）
npm run build       # 类型检查 + 生产构建（tsc --noEmit && vite build）
npm run preview     # 本地预览 dist 产物
npm run typecheck   # 仅类型检查
npm test            # 运行单元测试（vitest + jsdom）
npm run test:coverage  # 带覆盖率的测试
```

技术栈：React 18 + TypeScript + Vite 5 + MUI 5 + Tailwind 3（已关闭 preflight，与 MUI CssBaseline 共存）+ Zustand + IndexedDB（idb）+ CloudBase JS SDK（可选）。
